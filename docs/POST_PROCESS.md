# ポストプロセスと霧の実装状況

2026-11-23 のローカルインストールで `nimcli globals` を実行し、Render Globals の技法 ID と、実際に呼ばれる描画コードを照合した。タグの存在だけでは、Marathon の通常プレイでその技法が選択されるかは分からない。`FFFFFFFF` は技法参照なし。

## ポストプロセスの一覧

| 系統 | ゲーム側の代表技法 | nim での接続と残り |
|---|---|---|

| トーンマップ・グレーディング | `screen_area_global_lut3d*` (`80A745E5`～`80A74605`)、`color_grading_*` (`80A7460B`～`80A74651`)、`final_combine*` | SDR LUT、フィルムカーブ、色収差の入力を接続。ゲームのレイヤー・ティントマップ・HDR 出力校正とノイズ／歪み統合バリアントは未接続。 |

## 霧と煙の出所

| 経路 | ゲームデータ・シェーダー | nim の設定・推定 |
|---|---|---|
| 空／高度に応じた大気 | マップの大気コンポーネント `808084A0`、Outpost の空 LUT `80AC9019`、太陽経路、環境シーケンサ。最終照明 PS `80A74242` が extern 7 を読む。 | ゲーム側のコピー処理は未特定。環境 ch0F / ch18 を extern 7 +0x174 / +0x1A4 につなぐ。霧の既定倍率 0.25 は見やすさのための nim 設定。 |
| フロクセルの体積霧 | `cascade_raymarch_atmosphere_volume*` の密度 CS、散乱積分 CS `80A742F0`、ゲームの密度・ノイズチャンネルとテクスチャ。 | 1 カスケード、96 スライス、0.5〜256 m、履歴重み、ノイズ変種選択は推定。フロクセル外は高度ベースの大気式が担当する。 |
| 屋内の大気 | ゲームの密度 CS は extern 81 と `fog_density_interior` (chAB) を読む。 | ゲーム側の屋内マップ生成は未復元。真上からの深度を代理に使用。屋内密度は既定ゼロ、GUI の「屋内フォグ」でゲームデータの密度に切替。 |
| 局所ライトの光芒 | マップに配置されたライトの volumetrics 技法と元の合成・ぼかし技法。 | 別系統のため、基本霧をゼロにしても光芒が見える。密度スライスの生成元は未特定で、フロクセルから逆算するオプションは既定オフ。 |
| 煙などの粒子／半透明材質 | マップの FX 配置、粒子・材質のプログラムとテクスチャ。Outpost の天候スクリプトが書く `fog_amount` は調査範囲では材質と FX が読む。 | FX 式の VM と一部の二層粒子合成は未復元。大気倍率はこの経路を変更しない。`--no-fx` は粒子だけを切る比較条件。 |

Outpost の環境式で評価した時刻 0.890 では、元の ch0F / ch18 が 3 / 5.21333、ビューアの初期設定 0.25 倍では 0.75 / 1.30333。**ゲームの素材とシェーダーは確認済み。フレームの全パラメーターや実ゲームの見え方との一致は未確認。**

大気倍率 0 の Outpost 比較では、基準から 112,873 / 129,600 画素が変化した。さらにライトシャフトを外した比較でも 38,230 画素が変化した。元の密度 TFX は屋外密度の最大値で割るため、基本霧をゼロにしたときはフロクセル計算の入力だけに 0.0001/km の下限を与える。解析的な霧の入力はゼロ。

## ブルームの範囲

ブルームは画面全体の HDR から明るい成分を縮小・ぼかし、`screen_area_global_lut3d` の **t1** として全画面へ加算する。周辺減光は別の **t2** で、LUT 済みの色に乗算する。画面端の被写界深度はさらに別の準備パスで働く。

Outpost の固定露出 480×270 で、被写界深度・周辺減光を切ったままブルームだけをオン／オフした。中央 240×134 のうち 31,280 画素に差が出て、中央での最大差は 8 bit RGB の 28 階調。
